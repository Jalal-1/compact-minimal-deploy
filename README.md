# Compact minimal deploy

Deploy the OpenZeppelin native shielded token example to Midnight **Preprod**.

## 1. Install and compile

You need **Node.js 22+**, **Docker**, and the [Compact toolchain manager](https://docs.midnight.network/relnotes/compact-tools).

```sh
git clone https://github.com/Jalal-1/compact-minimal-deploy.git
cd compact-minimal-deploy
npm ci
compact update 0.31.0
npm run compile
```

## 2. Configure your wallet

```sh
cp .env.example .env
chmod 600 .env
```

Open `.env`, keep the Preprod URLs, and fill in:

| Setting | What to enter |
| --- | --- |
| `WALLET_SEED` | Your test wallet's master seed: 32 or 64 bytes in hexadecimal, not its recovery words. |
| `OWNER_NONCE` | Generate with the command below. |
| `CMA_SIGNING_KEY` | Generate with the command below. |
| `PRIVATE_STORAGE_PASSWORD` | A strong password, 16+ characters. Use uppercase, lowercase, numbers and symbols; avoid repeated or sequential runs of four characters. Quote the value in `.env`. |

Generate the owner nonce and maintenance key, then copy the two lines into `.env`:

```sh
node --input-type=module <<'JS'
import { randomBytes } from 'node:crypto';
import { sampleSigningKey } from '@midnight-ntwrk/compact-runtime';
console.log('OWNER_NONCE=' + randomBytes(32).toString('hex'));
console.log('CMA_SIGNING_KEY=' + sampleSigningKey());
JS
```

Keep `.env` private. It contains the keys needed to operate this example.

## 3. Start the proof server

Run this in a separate terminal and leave it running:

```sh
docker run --rm -p 127.0.0.1:6300:6300 \
  ghcr.io/midnight-ntwrk/proof-server:8.0.3 midnight-proof-server
```

## 4. Fund the wallet

Print the unshielded address for the seed in `.env`:

```sh
npm run address
```

Copy the **unshielded address** (`mn_addr_preprod1...`) into the [Preprod faucet](https://faucet.preprod.midnight.network/), complete the CAPTCHA and request test NIGHT.

The wallet also needs **DUST** to pay transaction fees. If it is not already generating DUST, [register its NIGHT for DUST generation](https://docs.midnight.network/guides/acquire-tokens) and wait for a spendable DUST balance. The faucet supplies NIGHT; this example does not perform the registration.

## 5. Deploy

Back in the project terminal:

```sh
npm run deploy
```

The script syncs the wallet, deploys one contract and waits for confirmation. It prints the contract address and transaction ID, and saves them in `deployment.json`. It does not mint tokens.

## Project layout

| Path | Contents |
| --- | --- |
| `contracts/Token.compact` | OpenZeppelin token contract. |
| `src/deploy.ts` | Deployment flow, numbered step by step. |
| `src/wallet.ts` | Wallet and transaction submission. |
| `scripts/address.ts` | Prints the unshielded address without connecting to the network. |
| `docs/deployment-notes.md` | Key handling, pinned versions and references. |
| `managed/token/` | Generated by compilation; ignored by Git. |
| `.private-state/` | Encrypted local key storage; ignored by Git. |

`npm run check` checks the TypeScript. Compilation and offline checks have passed; a live deployment has not yet been tested. See [deployment notes](docs/deployment-notes.md) for details.
