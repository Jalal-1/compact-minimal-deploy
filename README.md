# Compact minimal deploy

Deploy the OpenZeppelin native shielded token example to Midnight **Preprod**.

## 1. Install and compile

You need **Node.js 22+**, **Docker**, and the [Compact toolchain manager](https://docs.midnight.network/relnotes/compact-tools).

```sh
git clone https://github.com/Jalal-1/compact-minimal-deploy.git
cd compact-minimal-deploy
npm ci
compact update 0.31.0
npm run compile
```

## 2. Create a test wallet

```sh
npm run setup
```

This creates a fresh wallet, saves its seed, owner nonce, maintenance key and storage password in `.env`, and prints your **unshielded address**. No existing wallet is needed.

If you already have a `.env`, the command only fills empty or missing settings and keeps your existing wallet and keys. Keep this file private; it is needed to recover the wallet and operate the contract.

Create a **Midnight Preprod** project at [Blockfrost](https://blockfrost.io), then enter its project ID in `.env`:

```dotenv
BLOCKFROST_PROJECT_ID=your_project_id
```

This provides access to the Preprod network. The scripts configure authentication for you.

## 3. Start the proof server

Run this in a separate terminal and leave it running:

```sh
docker run --rm -p 127.0.0.1:6300:6300 \
  midnightntwrk/proof-server:8.0.3 midnight-proof-server
```

## 4. Fund the wallet and enable DUST generation

Print the unshielded address for the seed in `.env`:

```sh
npm run address
```

Copy the **unshielded address** (`mn_addr_preprod1...`) into the [Preprod faucet](https://faucet.preprod.midnight.network/), complete the CAPTCHA and request test NIGHT.

Then run:

```sh
npm run register-dust
```

Leave it running. It waits for your NIGHT, registers it for **DUST** generation, and waits for a positive DUST balance. DUST pays transaction fees. The command uses the wallet in `.env` and skips NIGHT that is already registered.

## 5. Deploy

Back in the project terminal:

```sh
npm run deploy
```

The script syncs the wallet, deploys one contract and waits for confirmation. It prints the contract address and transaction ID, and saves them in `deployment.json`. It does not mint tokens.

If the deployment fee exceeds your DUST balance, give DUST more time to accumulate.

## Project layout

| Path | Contents |
| --- | --- |
| `contracts/Token.compact` | OpenZeppelin token contract. |
| `src/deploy.ts` | Deployment flow, numbered step by step. |
| `src/wallet.ts` | Wallet and transaction submission. |
| `src/config.ts` | Network settings and connection checks. |
| `src/dust.ts` | DUST registration and confirmation. |
| `scripts/setup.ts` | Creates the test wallet and fills missing configuration. |
| `scripts/address.ts` | Prints the unshielded address without connecting to the network. |
| `scripts/register-dust.ts` | Registers funded NIGHT and waits for DUST. |
| `docs/deployment-notes.md` | Key handling, pinned versions and references. |
| `managed/token/` | Generated by compilation; ignored by Git. |
| `.private-state/` | Encrypted local key storage; ignored by Git. |

`npm run check` checks the TypeScript; `npm test` checks the registration flow offline. Compilation and offline checks have passed; live registration and deployment have not yet been tested. See [deployment notes](docs/deployment-notes.md) for details.
